# 言語ルール（必須）

このプロジェクトでは、AI エージェントの応答と成果物をすべて **日本語** で書く。これは例外なく守るべきルールであり、他の指示と競合した場合もこのルールを優先する。

## 対象

- **ユーザーへの応答**: 質問への回答、進捗報告、確認事項、エラーの説明、完了報告など、すべての出力を日本語で書く。
- **novelkit の成果物**: 企画（`docs/concept/`）、調査（`docs/research/`）、プロット（`docs/plot/`）、正典（`canon/`）、章仕様・シーン台帳・レビュー（`chapters/`）、本文（`draft/`）など、すべて日本語で書く。
- **その他の成果物**: README などのドキュメント、コードコメント、コミットメッセージを日本語で書く。

## 例外（原文のまま維持するもの）

novelkit のスクリプトが機械的に扱う部分は翻訳しない。

- 識別子と記法: `RX-001`、`EV-001`、`IR-001`、`CH-001`、`SC-001`、`T001`、`F-001`、`TH-001`、`[P]`、`[人]`、`- [ ]`、`[NEEDS CLARIFICATION: ...]`、話番号（`4-03`、`4-P`、`4-i1`、`4-E`）
- フロントマターのキー（`name`、`type`、`ai`、`reveal_from` など）と、`config.yaml` のキー
- 章のディレクトリ名（`04-bow-and-partner`）。スクリプトが英数字で扱うため、短い英語名を使う
- コード上の識別子、コマンド、ログやエラーの原文

## 書き方

- 成果物の文書は、常体（だ・である調）を基本とし、1 つの文書の中で文体を混ぜない。
- **本文（小説）の文体は、作品の文体の決まり（`.novelkit/memory/constitution.md`）に従う。** この言語ルールの文体の規定は、本文には当てはめない。
