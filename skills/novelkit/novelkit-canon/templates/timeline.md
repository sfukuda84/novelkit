# 年表

- 作中年の基準: （例: 主人公の誕生を 0 年とする。季節は春・夏・秋・冬）
- 人物の生年は、各人物ファイルの `born` に書く（年齢は計算で出す）
- シーン台帳の各話に `作中年` と `年齢` を書くと、check.py が年齢を検証する
