# novelkit-direction スキル（W3: 方向性の 3 案 → 選択）

同じ種から、読者体験の違う 3 つの方向を作って比べる（speckit-architecture の「3 系統の比較」と同じ形）。ここで選んだ方向が、壁打ち（W4）の出発点になる。

進捗の記録、モード、質問の規則は [`novelkit-status`](../novelkit-status/SKILL.md) に従う。

## 1. 入力

- `docs/concept/seed.md`（原文、ログライン、選択）
- `docs/research/wide.md`（類似作品、トロープ、読者、空いている席）
- 引数の希望

どちらかがなければ、欠けている工程（`novelkit-seed` / `novelkit-research-wide`）を案内する。

## 2. 手順

### ステップ 1: 発想を広げる

選んだログラインを中心に置き、マンダラート（3×3 の中心にテーマ、周囲 8 マス）で要素を広げる。周囲 8 マスは次の観点で埋める。

1. 主人公
2. 敵対
3. 舞台
4. 賭けられているもの
5. 感情の核
6. 結末の手触り
7. 読者の期待
8. 空いている席

有望なマスには SCAMPER の 7 つの操作を当て、案の候補を作る。

| 操作 | 例 |
|---|---|
| 代える | 主人公の職業、時代、舞台を代える |
| 組み合わせる | 別ジャンルの型を組み合わせる |
| 応用する | 他の分野の構造を借りる |
| 修正・拡大・縮小する | 規模を極端に変える |
| 転用する | 道具や設定を別の目的に使う |
| 除く | 定番の要素を抜く |
| 逆にする | 立場や順序を入れ替える |

この作業は `direction.md` の「発想メモ」に残す。完成させる必要はない。

### ステップ 2: 3 案を作る

候補から、**読者体験が互いに重ならない 3 案**を選ぶ。

- 3 案は、ジャンル、焦点（誰の物語か）、読後感のうち、少なくとも 2 つが違うようにする。
- 1 案は、種の原文に最も忠実な案にする。
- 1 案は、`wide.md` の「まだ空いている席」を最も強く狙う案にする。

案ごとに、次を書く。

| 項目 | 内容 |
|---|---|
| 一言 | この案を 1 文で |
| ログライン | 1〜2 文 |
| ジャンル | 主ジャンルと副ジャンル |
| 約束事と必須シーン | そのジャンルの読者が期待する条件と、必ず入れる場面（例: ミステリの「探偵が真相を明かす場面」、ロマンスの「二人が初めて出会う場面」） |
| 中心の考え | 物語を通して変わる価値（例: 孤立 → 連帯）と、その変化を 1 文で |
| 主人公 | 欲しいもの（Want）、本当に必要なもの（Need）、その間の溝 |
| 敵対 | 何が、なぜ阻むか（敵対者の言い分を 1 行で） |
| トロープの扱い方 | 主なトロープと、そのまま／逆転／外す／使わない／言及／脱構築のどれで扱うか |
| 類似作品との差 | `wide.md` の重なりが大きい作品に対して、何で差をつけるか |
| 読後感 | 読み終えた読者に残るもの |
| 読者と媒体 | 想定読者、発表先、分量の目安 |
| 危うさ | この案の弱点と、失敗したときの症状 |

### ステップ 3: 比較して提示する

3 案を比較表にまとめ、推奨案と理由を添えて示す。比較の観点は次の 7 つ。

1. 種への忠実さ
2. 空いている席を狙えているか
3. 類似作品との差の明確さ
4. 約束事の満たしやすさ
5. 長さへの耐性（その分量で失速しないか）
6. 書き手の既存の強み（既存作品があれば。新作では省いてよい）
7. 危うさ

安易な「外し」は警告する。トロープを逆にしただけで、読者体験が変わらない案は、差別化として数えない。

### ステップ 4: 選択

- **通常モード**: AskUserQuestion で案を選んでもらう。推奨案を先頭に置く。「組み合わせる」（例: A の設定に C の読後感）も受け付け、組み合わせた案を 1 つにまとめ直して、もう一度確認する。
- **自動モード**: 推奨案を採用し、`docs/auto-decisions.md` に記録する。ジャンル・読者・主人公の欲求と欠落は、見直しの優先度を「高」にする。

選んだ案を `direction.md` の「選択」に書く。選ばなかった案は消さず、`docs/concept/backlog.md` にも要点を残す（後で要素を拾えるように）。

## 3. 出力

- `docs/concept/direction.md`（様式: [templates/direction.md](./templates/direction.md)）
- `docs/concept/backlog.md`（選ばなかった案の要点を追記。様式は `novelkit-sparring` の [templates/backlog.md](../novelkit-sparring/templates/backlog.md)）

終わったら `W3` のチェックポイントを記録する。

## 4. 完了報告

- 3 案の一言と、選んだ案（組み合わせた場合はその内容）
- 選んだ案のジャンル、約束事と必須シーン、中心の考え
- 次の案内: `novelkit-sparring`（W4）
